# Portfolio Template

Template portfolio personal berbasis Next.js, TypeScript, dan CSS.

## Cara menjalankan
1. Install Node.js versi LTS jika belum ada.
2. Extract ZIP ini.
3. Buka folder project di VS Code.
4. Jalankan terminal:

```bash
npm install
npm run dev
```

5. Buka `http://localhost:3000`.

## Yang perlu kamu ganti
- `app/page.tsx`: nama, deskripsi, project, skills, GitHub, LinkedIn, dan email.
- `app/layout.tsx`: judul dan deskripsi website.
- `app/globals.css`: warna dan styling jika ingin disesuaikan.

Template ini belum menggunakan database karena kontennya disimpan langsung dalam file kode. Ini cukup untuk portfolio pribadi awal.
